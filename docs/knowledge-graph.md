# Runbook Knowledge Graph

The knowledge graph models every runbook as a **node** and the relationships
between them as **edges**. It powers the recommendation engine, "related /
follow-up / prerequisite" navigation, and gap analysis. The machine-readable
graph is generated by
[`tools/recommendation_engine.py --graph`](../tools/recommendation_engine.py)
and written to [`catalog/runbook-graph.json`](../catalog/runbook-graph.json).

## Model

```mermaid
flowchart LR
    subgraph Node
      N["Runbook<br/>id, title, category,<br/>difficulty, maturity_level"]
    end
    N -->|prerequisite| N2["Runbook"]
    N -->|related| N3["Runbook"]
    N -->|follow-up<br/>(category flow)| N4["Runbook"]
```

### Node attributes

| Attribute | Source |
|-----------|--------|
| `id`, `title` | front matter |
| `category`, `domain` | front matter |
| `difficulty` | metadata (derived from `risk_level` if absent) |
| `maturity_level` | maturity engine (L1–L5) |

### Edge types

| Type | Meaning | Derivation |
|------|---------|------------|
| `prerequisite` | Target should ideally be completed before source | curated dependency hints |
| `related` | High content/tag/keyword similarity | Jaccard similarity ≥ 0.25 |
| `follow-up` | Natural next step across categories | curated category flow map |

## How relationships are computed

**Similarity** combines tag overlap, keyword overlap, same-category and
same-domain signals, and shared agent support:

```text
similarity = 0.40*tag_jaccard + 0.25*keyword_jaccard
           + 0.20*same_category + 0.10*same_domain + 0.05*agent_overlap
```

**Prerequisites** are a curated, reviewed mapping (e.g. `incident-postmortem`
depends on `root-cause-analysis`; `monolith-to-microservices` depends on
`microservice-decomposition`). These encode real operational sequencing that
similarity alone cannot infer.

**Follow-ups** use a curated category-flow map (e.g. after a `reliability`
runbook, an `observability` or `cicd` runbook is a natural next step).

## Using the graph

```bash
# Rebuild the graph
python tools/recommendation_engine.py --graph

# Recommendations for a single runbook
python tools/recommendation_engine.py incident-postmortem
python tools/recommendation_engine.py rag-system-audit --json
```

Example recommendation output (abridged):

```text
Recommendations for: Incident Postmortem
Related:
  - Root Cause Analysis (score 0.51)
  - Production Readiness Review (score 0.45)
Follow-up:
  - CI/CD Pipeline Debugging (cicd)
Dependencies (do first):
  - Root Cause Analysis
```

## Applications

- **Navigation** — "What should I read next?" and "What must I do first?"
- **Onboarding paths** — chain prerequisite → runbook → follow-up into a
  guided learning/operational path per persona.
- **Gap analysis** — isolated nodes (few edges) surface under-connected areas
  where new bridging runbooks add the most value.
- **Agent orchestration** — multi-agent frameworks (AutoGen, CrewAI, LangGraph)
  can traverse `prerequisite` edges to decompose complex objectives into an
  ordered plan of runbook executions.

## Taxonomy

A complementary faceted taxonomy (categories, tags, domains, platforms, agents,
difficulties, risk levels, maturity) is generated to
[`catalog/taxonomy.json`](../catalog/taxonomy.json) by the search index builder
and drives filterable discovery in the docs portal and search tool.
